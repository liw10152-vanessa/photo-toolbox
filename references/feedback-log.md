# 反馈日志与版本历史

本文件记录 photo-layout-pdf Skill 的用户反馈、改进决策和版本变更。

## 记录格式

每条反馈按以下格式追加到「反馈记录」表：

| 字段 | 说明 |
|------|------|
| 日期 | YYYY-MM-DD |
| 来源 | 反馈者（如"用户A"/"自己测试"/"微信群反馈"） |
| 反馈内容 | 具体问题或建议，原话或精确描述 |
| 影响范围 | 涉及的功能/参数（如"间距默认值"/"DPI"/"cover模式"） |
| 状态 | 待处理 / 已采纳 / 已拒绝 / 待验证 |
| 处理结果 | 改了什么、对应版本、或拒绝原因 |
