# 反馈日志与版本历史

本文件记录 photo-toolbox Skill 的用户反馈、改进决策和版本变更。

## 记录格式

每条反馈按以下格式追加到「反馈记录」表：

| 字段 | 说明 |
|------|------|
| 日期 | YYYY-MM-DD |
| 来源 | 反馈者（如"用户A"/"自己测试"/"微信群反馈"） |
| 反馈内容 | 具体问题或建议，原话或精确描述 |
| 影响范围 | 涉及的功能/参数（如"间距默认值"/"DPI"/"cover模式"） |
| 状态 | 待处理 / 已采纳 / 已拒绝 / 待验证 |
| 处理结果 | 改了什么、对应版本、或拒绝原因 |

## 版本历史

| 版本 | 日期 | 变更摘要 |
|------|------|---------|
| v1.0 | 2026-09-02 | 初始版本：9张/页默认，contain模式，margin=16, gap=3, dpi=200 |
| v1.1 | 2026-09-02 | 新增方向自动分组（超竖/竖/正方/横版四类，同类连续排列） |
| v1.2 | 2026-09-02 | 品质提升：异常处理分支、8条反例黑名单、2处检查点、测试用例扩到7个 |
| v1.3 | 2026-09-03 | 新增 Word 排版（图下留备注）和照片水印（角标/居中/平铺），测试用例扩到12个 |
| v1.4 | 2026-09-03 | Skill 更名 photo-layout-pdf → photo-toolbox，匹配三功能定位 |
| v1.5 | 2026-09-03 | 水印升级：默认位置改正中偏下(center-low)；新增角标/居中旋转(--angle)；新增输出长边上限(--max-size 4000 提速)与PNG无损输出(--format png)；测试用例扩到14个 |
| v2.0 | 2026-09-04 | 开源化改造：新增首次使用引导流程（Agent 连问 PDF 排版/Word 排版/水印偏好，存 user-preferences.json）；删除个性化水印示例；新增 README/LICENSE/.gitignore/user-preferences.json.example；测试用例扩到15个 |
| v2.1 | 2026-09-04 | 新增功能四：证件照排版（layout_id_photo.py，一寸/二寸自动裁切+5寸/6寸相纸排版打印，300dpi）；引导新增证件照偏好；测试用例扩到17个 |
| v2.2 | 2026-09-06 | 开源传播优化：证件照提升为主打功能并放到首屏；README 新增"局限（Limitations）"章节；SKILL.md 描述补充证件照触发词 |

**使用说明**：
- 每次用户使用本 Skill 后提出问题、建议或不满，AI 必须将反馈追加到上表
- 积累 3 条以上「待处理」反馈，或收到严重问题时，建议用户触发 Darwin Skill 进行优化（说"用达尔文优化 photo-toolbox"）
- 优化完成后，更新版本历史表，并将对应反馈标记为「已采纳」
