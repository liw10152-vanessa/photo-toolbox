# 反馈与持续改进流程

本文件记录 photo-layout-pdf Skill 的持续进化流程。仅在需要记录反馈或触发优化时读取，日常使用不需要加载。

## 记录反馈

将用户反馈追加到 `feedback-log.md` 的反馈记录表中，包含：日期、来源、反馈内容、影响范围、状态（待处理）。不要只在对话里回应而不记录——反馈日志是持续改进的唯一依据。

## 触发优化

当出现以下任一情况时，主动建议用户触发 Darwin Skill 进行系统性优化：
- 反馈日志中积累了 3 条以上「待处理」反馈
- 用户报告了严重问题（如脚本报错、PDF 无法打开、照片方向错误）
- 用户明确说"优化一下这个 skill"或"改进一下"

触发方式：告诉用户说「**用达尔文优化 photo-layout-pdf**」即可。Darwin Skill 会自动读取本目录的 `test-prompts.json` 作为测试基准，执行评估→改进→验证循环。

## 优化后更新

Darwin 优化完成后：
1. 将反馈日志中对应反馈的状态改为「已采纳」，填写处理结果
2. 在 `feedback-log.md` 的版本历史表中追加新版本记录
3. 告知用户本次优化改了什么、效果如何

## 测试基准

`test-prompts.json` 包含 7 个典型测试用例，覆盖：
1. 基础场景：9张照片每页9张，A4，contain模式
2. 多页场景：15张照片每页4张，150 DPI
3. 特殊参数：cover裁剪填满，每页6张，A3纸
4. 方向分组：20张混合方向照片，自动分组
5. 边界情况：1张照片
6. 大量照片：50张照片
7. 关闭分组：按原顺序排列

Darwin 优化时必须用这些测试用例做实测验证，确保改动不会破坏已有功能。新增重大功能时，应同步补充对应的测试用例到 `test-prompts.json`。
